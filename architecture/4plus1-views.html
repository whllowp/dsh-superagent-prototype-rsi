Effects 队列：六类副作用

类别做什么并发重试/退避
assessment把评估候选卡送入主 Session 回合（送达即启动截止计时）42s 起倍增至 60s
launch启动派工：prepare 命令 → worker Session → 派工消息空闲槽位数瞬时故障 5s→300s ×3；prepare 失败即工单失败
delivery把等待中的 Input 按序投给运行中的 Assignment42s 起倍增至 60s（失败显示在工单上）
relayworker 报告/提问、人的追问 → 主 Session 回合（保序）12s 起倍增至 60s
notice不打扰式通知注入主 Session（保序）12s 起倍增至 60s
reply经 Source 渠道发出 Outbox 消息（同工单同会话保序）15s→300s；渠道消失则丢弃留痕
暂停（pause）：停止派工、新评估、超时与投递，但 Source 继续记录 Trigger；重启后按存储恢复——中断的 Assignment 带恢复备注续跑，最老的 Ticket 优先。
